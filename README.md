# Express + TypeScript + PostgresSQL Project

Bookstore backend web app built using express, typescript and postgres as database

## Installation

1. Clone the repo

```bash
  git clone https://github.com/simon-kiros/bookstore-backend.git
```

2. Install NPM packages

```bash
  cd bookstore-backend
  npm install
```

3. Configure your database info in the .env file

4. Run the database seeder

```bash
  npm run seed
```

5. Run the project

```bash
  npm run dev
```

5. Run the swagger doc at

```bash
  http://localhost:8000/docs
```
